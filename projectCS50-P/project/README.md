# Study Time Tracker
#### Video Demo:  https://youtu.be/T40g7dTInHE?si=-eDrJiN3OjIqQahh

#### Description:

Study Time Tracker is a command-line Python application designed to help students log and analyze their study habits. The program allows users to record individual study sessions by subject and duration, then calculates total and daily study time automatically.

The project was built as a final project for CS50P and demonstrates file handling, data persistence, modular program design, and automated testing with pytest.

The main file, project.py, contains the application logic and user interface. Users interact with the program through a simple menu system that allows them to log study sessions, view total study time, or view a summary of today’s study activity.

Study data is stored in a CSV file called study_log.csv, allowing information to persist between program runs. The program uses Python’s datetime module to automatically associate study sessions with the current date.

The project also includes test_project.py, which contains automated tests for the program’s core functions. These tests verify correct behavior for logging sessions, calculating total study time, calculating daily totals, and handling invalid input.

This project was designed to be practical, easy to extend, and representative of real-world Python usage. Possible future improvements include per-subject analytics, graphical output, and data visualization.
